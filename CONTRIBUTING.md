# Contributing to Maegae

Thank you for your interest in contributing to Maegae!

## Getting Started

1. Clone the repository. Fork it first if you don't have write access.
2. Create a branch for your changes.
3. Run `./gradlew build` to verify your changes.

## Guidelines

- Follow the existing architecture and coding conventions.
- Keep changes small, focused, and easy to review.
- Avoid unnecessary dependencies and complexity.
- Include meaningful tests for bug fixes and new features.

## Commit Messages

Write clear, concise commit messages.

Conventional Commits are recommended but not required.

Examples:
- `feat: add tool registry`
- `fix: handle invalid JSON-RPC requests`
- `test: cover tool execution timeout`

## Pull Requests

- Clearly describe the purpose and scope of your changes.
- Link related issues when applicable.
- Ensure the build and relevant tests pass.
- Discuss significant changes or new features in an issue before implementation.

## Issues

Use GitHub Issues to report bugs or suggest new features.
